# Bildplätze

Alle Bilder, die die Website erwartet. Eine Datei mit genau diesem Namen in den passenden Ordner
legen – sie erscheint automatisch. Solange ein Bild fehlt, zeigt die Seite eine feine Schraffur
und oben links den erwarteten Dateinamen.

Andere Dateiendung (z. B. `.webp` oder `.png`)? Dann im HTML das `data-bg="…"` anpassen.
Die 3D-Modelle sind keine Bilder – die kommen aus `assets/3d/` (siehe `../README.md`).

## Empfohlene Größen

| Art | Seitenverhältnis | Größe |
|---|---|---|
| `hero.jpg` (Seitenkopf), `parallax.jpg`, Bänder | breit, Motiv eher rechts | 1920×1080 (mind. 1600 breit) |
| Bilder neben Text (`intro.jpg`, `planet.jpg` …) | 4:3 | 1200×900 |
| Feature-Bilder | 4:3 | 800×600 |
| Vorschaubilder in Listen (`news-*`, `devlog-*`, `event-*`, Themen) | 16:10 | 640×400 |
| Hochformat (`install.jpg`, `roadmap.jpg`, `mitglied-*` …) | 4:5 | 800×1000 |
| Screenshots / Galerie | beliebig, wird zugeschnitten | mind. 1280×720 |
| `architektur.png` | 21:9 | 2100×900 |
| `logo.png` | 1:1, transparent | 256×256 |
| `og-image.jpg` (Vorschau beim Teilen) | 1,91:1 | 1200×630 |

Tipp: Fotos als `.jpg` (Qualität ~80 %), Grafiken mit Transparenz als `.png`. Hintergrundbilder
über 500 KB machen die Seite langsam – vorher verkleinern.
